## Outcome

Turn the commissioned memory fab's current layer-two particle excursion into one exact, immutable Design decision shared by humans and Agents: commission the explicit particle-suppression mode only if it improves the current locked factory without regression, otherwise retain the measured quality loss as automatically expiring bounded-deferred evidence and advance the work queue.

## Context

Compatible Run `089-simulate` ranks verified yield and quality loss second. Two of twelve inspected lots acquire critical-dimension plus particle-contamination defects at `etch-l2`, enter rework, and are repaired; the selected `closed-loop-control` mode prevents only the third authored latent-electrical instance.

The project catalog already contains a physically explicit `particle-suppression` mode at `13/10` active power. Historical Design bounded it against older factory revisions, but the broad current provider makes that option reachable only from one obsolete revision hash. Current TypeScript research against the commissioned Blueprint shows the mode still improves the local mixed-quality result from ten to eleven first-pass lots, but reduces aggregate score by `0.451773`, reduces the quality-excursion case by `0.861116`, and reduces the lithography-interruption case by `1.541480` while losing one on-time lot.

Those numbers are useful research, but an ad-hoc script is not current immutable authority for either the CLI or Studio. The exact current contributor, metric, patch, five-case decision, and invalidation boundary must pass through the same Design and Workbench contracts as every other industrial decision.

## Scope

### In scope

- Add one focused, project-local Design Program for the current `etch-l2` quality-excursion contributor.
- Add a structurally guarded TypeScript proposal that selects the already-authored `particle-suppression` mode and declares the exact current `introducedDefectInstances` target.
- Run the unchanged locked five-case Benchmark and preserve the result as content-addressed evidence.
- Commission only a promotion-safe winner; otherwise derive the existing strict bounded-deferred Workbench disposition without hiding or rescoring the physical loss.
- Keep the next action, CLI JSON/human output, Studio route, source evidence, and durable design narrative identical for humans and Agents.

### Out of scope

- Weakening current-best, hard-outcome, Benchmark, on-time, scrap, or escape guardrails.
- Editing defect excursions, preventing critical-dimension defects, adding random yield, or inventing hidden quality multipliers.
- Treating repaired defects as harmless or declaring the physical loss solved.
- Reopening historical factory revisions, adding compatibility aliases, or making the broad provider's obsolete revision gate authoritative for the current focused decision.
- Combining unrelated release, logistics, maintenance, or back-end interventions into this exact-target Program.
